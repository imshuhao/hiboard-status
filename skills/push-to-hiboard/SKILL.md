# 按需推送到负一屏

把当前对话中的内容（报告、清单、总结等）组装成卡片，推送到用户手机负一屏。

## 步骤

### 1. 组装 JSON 并写入临时文件

用 Write 工具创建 JSON 文件（勿用命令行参数传正文——markdown 含引号/反斜杠会被 shell 转义破坏）：

```json
{
  "summary": "7月26日日报 · 3 件要事",
  "content": "# 正文标题\n\nmarkdown 正文……",
  "source": "日报",
  "result": "推送完成",
  "topic": ""
}
```

| 字段 | 必填 | 显示位置（映射反直觉，勿凭直觉改） | 写法 |
|---|---|---|---|
| `summary` | ✅ | **负一屏列表里的卡片标题**——用户最先看到的文本 | 一句带信息量的话，含数量/结论，≤60 字符 |
| `content` | ✅ | 点开后的正文（markdown） | 上限 28,000 UTF-16 码元，emoji 计 2 |
| `source` | 可选 | 展开态**主标题** + 列表态"任务来源" | 内容类别，如「日报」「购物清单」；默认「Claude Code 推送」 |
| `result` | 可选 | 展开态副标题 | 默认「推送完成」 |
| `topic` | 可选 | 不显示，决定卡片归属 | **见下方主题卡警告** |

### 2. 执行推送

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/hiboard_hook.py" --push <JSON文件路径>
```

（若 `${CLAUDE_PLUGIN_ROOT}` 未解析，脚本位于 `~/.claude/plugins/marketplaces/imshuhao/scripts/hiboard_hook.py`。）

### 3. 报告结果

- exit 0：告知用户推送成功，卡片会出现在负一屏顶部。
- exit 1：读脚本 stdout 与 `~/.claude/hiboard/push.log` 末尾几行，按错误码给出准确指引：
  - `0000900034` → 授权码无效，引导重新获取（负一屏 → 动态管理 → 关联账号）
  - `0000500002` → 正文超长，精简后重推
  - `0000400001` → 推送配额达上限，告知用户稍后（可能次日）再试，勿重试轰炸
  - `82600013` → 负一屏推送开关关闭，引导开启

## 卡片归属规则

- **默认（不填 topic）**：写入 3 个轮转卡位之一，负一屏保留最近 3 次推送，自动复用最旧卡位，永不堆积。
- **填 topic**：固定卡片，同主题永远覆盖同一张卡。**警告：负一屏卡片无删除接口，主题卡一旦创建永久存在**——只给真正周期性的内容用（如每天更新的日报），一次性内容一律走默认轮转。

## content 写作约束（渲染端实测）

- ✅ 可用：标题、粗体斜体删除线、列表、表格、引用、代码块（带语法高亮）、链接、图片
- ❌ 禁用：任务列表 `- [x]`（原样输出字面量）、表格对齐标记 `:--:`（一律左对齐）
- 不要在正文里自己写时间戳或"AI 生成"声明——负一屏会自动追加页脚
- 长度校验按 UTF-16 码元（emoji 计 2），不是字符数
